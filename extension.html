Got Questions?

Extension FAQs

Is the FrankPass browser extension completely free?
Yes, 100% free! The core Instant Guest Mode allows you to auto-detect domains and autofill passwords with 1,000,000 PBKDF2 iterations for free forever with zero signups and zero advertisements. Pro is an optional upgrade only if you want to save encrypted profiles with 4-digit PIN lock.
When will the extension launch on the Chrome Web Store?
The extension is currently completing final cryptographic and security audits. Official release announcements will be published on our X channel (@frankpasshq). In the meantime, you can use the 100% offline Web App and PWA on any browser right now.
How does the extension protect against phishing clones?
Because passwords are mathematically derived from the exact active domain string, a spoofed clone site (e.g. g00gle.com) automatically derives an entirely different, useless dummy password. Your real password for google.com is never generated or exposed to the phishing site.
Can I use 1 Pro license across multiple browsers on the same PC?
Yes! FrankPass Pro licenses are hardware-bound to your PC. A single license key unlocks Pro across Chrome, Edge, Brave, Firefox, isolated clean profiles, and the upcoming Windows Desktop App on that physical computer with zero extra charges.
