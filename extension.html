Yes, 100% free! The core Instant Guest Mode allows you to auto-detect domains and autofill passwords with 1,000,000 PBKDF2 iterations for free with zero signups and zero advertisements. Pro is an optional upgrade only if you want to save encrypted profiles with 4-digit PIN lock.

How does the extension protect against phishing clones?
Because passwords are mathematically derived from the exact active domain string, a spoofed clone site (e.g. g00gle.com) automatically derives an entirely different, useless dummy password. Your real password for google.com is never generated or exposed to the phishing site.

Common Inquiries

Frequently Asked Questions

Quick answers regarding extension installation, hotkeys, and mathematical isolation.

How does the extension autofill without a central database? ▾

FrankPass does not possess or communicate with any password database. When you visit a website (e.g., github.com), the extension reads the active domain name and computes a SHA-512 cryptographic hash using 1,000,000 PBKDF2 rounds directly in your computer's RAM. The moment the tab closes, the calculated credential evaporates from memory.

Which operating systems and browsers are supported? ▾

The browser extension runs seamlessly on Windows, macOS, and Linux across Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, and Opera. For mobile phones (Android and iPhone), FrankPass provides a standalone PWA (Progressive Web App) that installs in 1 click.

What hotkey triggers the 1-click password autofill? ▾

On Windows and Linux, press Ctrl+Shift+F. On macOS, press Command+Shift+F. The extension instantly detects the active input field and populates your mathematically derived password in 0.1 seconds.

Does FrankPass require creating an account or email signup? ▾

No. Free Instant Guest Mode requires zero signups, zero phone numbers, and zero email addresses. The founder operates on a strict Zero-PII oath: if the math can function offline without your identity, we will never ask for it.
