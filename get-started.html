How to Use FrankPass

Master stateless security across all 4 platforms: the Instant Web App, 100% Free Browser Extension, Pro Hardware-Bound Profiles, and Offline Mobile PWA.

🌐

1. FrankPass Web App (Universal Access)

Zero Install · Any Browser · 100% Client-Side WebCrypto

  • 1 Open frankpass.com in any browser on PC, Mac, Linux, iOS, or Android. Zero account sign-up or email is required.
  • 2 In the Platform field, enter the service name (e.g. github, gmail, amazon).
  • 3 Enter your personal, memorable Master Secret Key (e.g. blue umbrella flies over desert sunset 482 - do not use this example).
  • 4 Click Generate Password. 1,000,000 PBKDF2-HMAC-SHA512 iterations calculate your high-entropy password in RAM locally in ~0.8s with massive offline cracking resistance.
  • 5 Copy the password into your login form. When needed again, typing the same inputs recalculates the exact same password deterministically.
💡 Zero Database Security: Because passwords are mathematically calculated rather than stored, there is literally no database or encrypted cloud file in existence to breach.

2. Free Browser Extension (1-Click Guest Autofill)

100% Lifetime Free · Domain Detection · Zero Clipboard Exposure

  • 1 Install the extension from /install.html into Chrome, Brave, Edge, or Firefox.
  • 2 Click the browser Puzzle Icon (🧩) → Pin FrankPass (📌) to your toolbar.
  • 3 On any website login page, press Ctrl + Shift + F (Mac: ⌘ + Shift + F) or click the FrankPass icon.
  • 4 The extension automatically detects the domain name. In Instant Guest Mode (100% Free Forever), type your Master Secret Key.
  • 5 Click ⚡ Direct Autofill to inject the password straight into the input field via DOM API without touching the system clipboard.
🛡️ Zero-Clipboard Defense: Infostealer malware continuously monitors operating system clipboard buffers. FrankPass direct DOM autofill bypasses the clipboard entirely, making credentials invisible to spyware.
