💡 What is a Master Secret Key in Plain Words?

Your Master Secret Key is a private mathematical signature that exists only in your memory. It is never stored on any server, never saved in a database, and never sent across the internet.

Instead of saving 100 different passwords in an online cloud vault (which can get breached), you remember just one memorable secret phrase. FrankPass uses pure client-side mathematics (1,000,000 PBKDF2 rounds) to instantly calculate a distinct, high-entropy password for every website you visit.

[Platform Domain] + [Your Secret Key] + [Counter (1-999999)] = Deterministic High-Entropy Password (100% reproducible across all devices offline).

Always reproduce the exact same password at any time on any device without internet. 🛡️ FrankPass Threat Boundary: What It Prevents vs. User Responsibility

Scientific cybersecurity demands transparent boundary definition. Here is the direct comparison of what stateless cryptography shields versus your essential human responsibilities:

✅ FrankPass Prevents: Centralized Cloud Vault Breaches
No master secret keys, passwords, or encrypted vault blobs are ever stored on any server or database. A cloud vault hack is 100% architecturally impossible.

A data breach on one website never exposes or affects passwords on other platforms due to mathematical domain isolation. Furthermore, if you accidentally land on a deceptive clone or phishing website (e.g. faceb00k.com instead of facebook.com), FrankPass mathematically calculates a password bound strictly to that clone domain, meaning your genuine facebook.com password is never leaked to the phisher!
⚠️ BUT User Responsibility & Founder Recommendation: Because FrankPass derives passwords from whatever domain you provide, entering a phishing domain generates credentials for that rogue site.

✅ FrankPass Prevents: OS Clipboard Buffer Interception
The FrankPass Extension injects credentials directly into webpage input elements without copying them to the OS clipboard, shielding you from generic background clipboard sniffers.
⚠️ BUT User Responsibility & Defenses: If a device is infected with active spyware or keyloggers, inputs can be captured at the operating system level.

Good vs. Bad Secret Keys: The FrankPass Reality

Your Secret Key is not your final password. FrankPass converts your input into a high-entropy password using 1M PBKDF2 rounds. What matters is easy personal memory + unguessability.

❌ Avoid: High Risk of Forgetting or Dictionary Attacks

Avoid anything easily guessed via OSINT or prone to typing errors:

  • abcxyzcxbc (Random scrambled letters you will forget)
  • qzwxplkjhf987 (Gibberish with no meaning to your brain)
  • P@$$w0rd!#%9 (Complex punctuation prone to mobile typing errors)
  • 198765432100 (Long random numbers with zero natural hook)
  • hello / india / manikant (Common single words in dictionary lists)
🛡️ Typing Protection:
If you accidentally add punctuation symbols, FrankPass Normalization strips them in RAM, preventing broken passwords.
