Four simple steps. One deterministic mathematical function. One unique password. No storage.

Username / Account (Optional)

Use only if you manage multiple accounts on the same site (e.g. personal vs work). If you have only one account, leave it blank. Establish a personal rule and follow it consistently.

2

Enter Site / Platform

Type any platform name or paste a URL. FrankPass normalizes it automatically - facebook.com, www.facebook.com, or just facebook all produce the exact same result.

3

Your secret key is the master seed. It never leaves your device memory. 1,000,000 PBKDF2-HMAC-SHA512 iterations compute a mathematically isolated cryptographic seed locally.

The stateless advantage

Why not a cloud password manager?

Cloud vaults can be breached

Every major password manager has had a security incident. When they store your encrypted vault online, they create a honeypot - a single point of failure that makes your entire digital life a target for one attack.

Zero Centralized Credential Storage

FrankPass operates without centralized servers, cloud databases, user accounts, or synced vault files. Your derived credentials exist only in volatile device RAM during generation.

Works when the internet doesn't

Cloud managers fail when their servers go down or when you're offline. FrankPass is a PWA - install it once and it operates offline via local browser WebCrypto, even in airplane mode.
