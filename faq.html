Frequently Asked Questions

Everything you need to know about how FrankPass keeps your passwords secure - without storing any of them.

What is FrankPass (or Frank Pass)?
FrankPass (often written as Frank Pass) is a stateless, deterministic password and PIN generator created by Master Manikant Yadav. The name combines "Frank" (standing for 100% honesty, zero trackers, and radical transparency) and "Pass" (for unbreakable deterministic passwords and PINs). Instead of storing your passwords in a cloud vault, it derives them mathematically each time from three inputs you provide: a platform name, your secret key, and a variant number. It uses PBKDF2 and HMAC-SHA512 with 1,000,000 iterations-running entirely in your browser via the Web Cryptography API. Zero cloud, zero storage, zero accounts. The same inputs always produce the same password, on any device, forever.
How is FrankPass different from traditional cloud password vaults?
Traditional password managers store an encrypted database vault on cloud servers, creating a centralized target for attackers. FrankPass stores nothing. There is no cloud vault to steal, no file to crack, and no database to breach. Your passwords are re-derived mathematically on demand from inputs that never leave your device's memory. The security model is architecturally zero-knowledge.
How does FrankPass solve the problem of forgotten ATM and UPI PINs?
Many people create 4-digit or 6-digit ATM and UPI PINs and later forget them, or write them down insecurely. With the FrankPass PIN Generator, you use your existing Master Secret Key and Bank Name (such as SBI ATM or PhonePe) to calculate your numeric PIN. You set that exact calculated PIN when creating your card or UPI PIN at the ATM machine or banking app. Later, you never need to remember or save the PIN anywhere - whenever you need it, simply re-calculate it on FrankPass instantly with pure offline math.
If FrankPass updates to a new version (e.g. from v3 to v4), will my old passwords change?
No, absolutely never. The core cryptographic password derivation algorithm (PBKDF2 with HMAC-SHA512 at 1,000,000 iterations and Base94 character mapping) is permanently frozen, immutable, and mathematically constant. The same platform name and secret key will generate the exact same cryptographic password 10, 20, or 50 years from now. Version numbers (like v3.2.7 → v3.2.8) only represent frontend design enhancements, dark/light theme contrast refinements, and offline PWA speed optimizations. Your passwords will never change.
What happens if the FrankPass site goes down?
Nothing changes for you. If you've installed FrankPass as a PWA (tap the install icon in your browser), it works fully offline and permanently - even if this domain expired tomorrow. The algorithm is open, documented, and based entirely on web standards (PBKDF2 + HMAC-SHA512), so it can always be re-implemented by anyone. Your passwords are mathematical outputs, not stored data - they can't disappear because they were never stored.
Is my Secret Key stored anywhere?
Never. Your Secret Key is processed only in your browser's volatile memory and is never transmitted to any server, never written to disk, never logged anywhere. To reinforce this, FrankPass automatically clears the Secret Key input field after 2 minutes of inactivity. No network request is ever made during password generation - you can verify this by opening your browser's network tab before generating a password.
Does FrankPass work completely offline?
Yes. Once the page has loaded once, you can disconnect your internet and the generator continues to work perfectly. The entire cryptographic computation happens inside your browser using the Web Cryptography API - no server is contacted during generation. For permanent offline access, install FrankPass as a PWA: look for the install icon in your browser's address bar, or go to your browser menu and choose "Add to Home Screen". After installation, FrankPass works like a native app - no internet required, ever.
What happens if I forget my Secret Key?
Because FrankPass is zero-knowledge and stateless, there is no "Forgot Password" feature and no recovery mechanism - by design. Your Secret Key is the mathematical foundation of every password you've ever generated with it. If you forget it, you will need to reset your passwords on every affected website individually. This is why we strongly recommend choosing a Secret Key that is deeply memorable to you - a personal phrase, a pattern based on a meaningful memory, or a lyric only you know. Write it down and store the physical copy somewhere extremely secure (like a safe), separate from your devices.
Is FrankPass open source?
The cryptographic engine uses only open web standards - PBKDF2 and HMAC-SHA512 via the browser-native Web Cryptography API. There is no proprietary or custom cryptography. The algorithm is fully transparent and auditable: the entire derivation logic is in frankpass-core.js, which you can inspect in your browser's developer tools. No black boxes. No security through obscurity. The algorithm is documented in full in the documentation.
Which browsers and devices does FrankPass support?
FrankPass works on any browser that supports the Web Cryptography API - which means all modern browsers: Chrome, Firefox, Safari, Edge, Brave, Samsung Internet, and Opera, on desktop and mobile. No plugins or extensions are needed for the free web generator. The browser extension (Pro feature) currently supports Chrome, Firefox, Edge, and Brave.
Why are prices different for different countries?
FrankPass uses purchasing power parity (PPP) pricing to make the Pro extension accessible globally. Users in India see prices in Indian Rupees (INR) that reflect local purchasing power, while users in other countries see USD pricing. Your country is detected automatically based on your selection in the country dropdown, and the pricing updates immediately. This is the same approach used by platforms like Spotify and Netflix for regional pricing.
What does the Variant counter do, and when should I use it?
Think of the Variant as your Password Number (Rotation Counter 1 to 999). The permanent default is 1. Two situations call for changing it: first, if a website forces you to change your password periodically - simply increment the Counter from 1 to 2 (or any number up to 999) to generate a brand-new, secure password for that platform without changing your Secret Key. Second, if you believe your account was compromised - incrementing the Variant immediately invalidates the old password and produces a fresh one. Always remember which Variant number you're using for each platform, since you'll need to match it every time you log in.
Can I control password length, and what if a website rejects my password?
Yes. Use the length slider in Advanced Options to set any length between 8 and 32 characters. The Max preset automatically sets it to 32. If a website rejects your password - some older sites have maximum length limits or prohibit symbols - try these steps in order: first, lower the length slider; second, switch the Profile to "Simple" (alphanumeric, no symbols); third, generate again. Critically: note exactly which settings you used, because you must use those same settings every time you log in to that website.
Is the browser extension free, and do I need FrankPass Pro?
Yes, the browser extension is 100% free to install and use!

In Instant Guest Mode, the extension automatically detects active website domains and provides 1-click password generation and autofill completely free forever with zero storage and zero registration.

FrankPass Pro is an optional upgrade for power users that adds Local Encrypted Multi-Profile Vaults with a 4-digit quick PIN lock, allowing you to save different master keys locally on your computer without re-typing them every session.
Can I use just 1 or 2 words as my Secret Key? Is it secure?
Yes, absolutely! Just follow this simple rule: If you choose a short 1-word or 2-word Secret Key (such as blue lotus or peaceful), always enter your Email or Username in the generator's Username field. Because your email address is globally unique to you, FrankPass's 1,000,000 PBKDF2 iterations will produce a 100% unique password that will never collide with or match anyone else's password.

💡 Tip: If you prefer leaving the Username field blank, simply choose a 3-5 word natural sentence (like two hot samosas with green chutney) as your Secret Key. Explore 50+ ideas in our Secret Key Guide →
If a website suffers a data breach, can attackers reverse my Secret Key?
No, mathematically impossible. FrankPass uses 1,000,000 PBKDF2 iterations with HMAC-SHA512. Cryptographic one-way hashing ensures that even if an attacker obtains your generated password from a compromised website database, they can never reverse it back to determine your Master Secret Key. All your other accounts remain 100% secure.
Can I use the exact same Secret Key for the FrankPass PIN Generator?
Yes! FrankPass incorporates completely isolated cryptographic context salts for passwords and numeric PINs. Using the same Secret Key on the FrankPass PIN Generator produces an independent 4-digit or 6-digit PIN with zero cryptographic correlation to your alphanumeric passwords.
