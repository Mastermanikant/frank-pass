PART 1: CRYPTOGRAPHIC SPECIFICATION & ZERO-STORAGE INVARIANTS
--------------------------------------------------------------------------------
Core Philosophy: "A password never stored in a centralized database eliminates centralized server database breach exposure."

Key Cryptographic Parameters:
1. Algorithm: PBKDF2 (Password-Based Key Derivation Function 2) using HMAC-SHA512.
2. Work Factor (Iterations): 1,000,000 rounds computed directly in local browser WebCrypto RAM.
3. Salt Context: Derived deterministically from normalized Site/Platform (and optional Account/Username).
4. Subdomain Isolation: Subdomains (e.g. `aws.amazon.com` vs `amazon.in`) are deterministically isolated to generate distinct passwords.
5. Modulo Bias Elimination: Output character mapping uses Golden Base-32 Modulo (2^5 = 32) eliminating visually confusing characters (O/0, l/1, S/5).
6. Zero Cloud Storage: 0 bytes are transmitted over the network; the entire calculation executes locally offline via Web Cryptography API.

PART 2: HOMEPAGE COMPONENT ARCHITECTURE & LANDMARK HTML
--------------------------------------------------------------------------------
The homepage is structured into clearly delineated semantic modules with structured landmark comments:

1. HERO SECTION & FOUNDER COMPACT TRUST CARD:
   - PC Mode: Side-by-side balanced card with Founder Photo (100x120px) on the left, and Name (`Master Manikant Yadav`), Role (`Founder & Software Architect`), clickable project chips (`[ FrankPass ]` and `[ FrankBase ]`), and a 2-row x 3-column compact social channels grid on the right.
   - Mobile Mode: Stacked layout with top photo+info row, full-width 2x3 social grid, and expandable drawer button (`Read Founder Story & Cryptographic Proofs`).

2. GENERATOR CORE CARD:
   - Dismissible First-Time Tip Toast with localStorage memory.
   - Optional Username/Email input with Multi-Account Isolation guidance.
   - Smart Site/Platform input with auto-normalization for URLs and app names.
   - Master Secret Key input with dedicated '?' popover containing security guidance and the Zero-Recovery Notice.
   - Generated Password box with 1-click copy, real-time entropy calculation, and auto-mask toggle.

3. THE STATELESS WORKFLOW (HOW IT WORKS):
   - Structured into 4 Glass Step Cards in a 2x2 Compact Grid (`max-width: 820px; margin: 0 auto;` on PC and 1-column on Mobile).
   - Card 1: Username / Account (Optional) - Explains multi-account isolation.
   - Card 2: Enter Site / Platform - Explains URL/app name normalization.
   - Card 3: Enter Master Secret Key - Explains 1,000,000 PBKDF2 cryptographic seed.
   - Card 4: Copy, Use & Regenerate - Explains deterministic offline re-calculation.
   - Header Alignment: Each card features a horizontal `.step-card-header` aligning the step number badge (1, 2, 3, 4) on the top-left and the icon box on the top-right.

4. MULTILINGUAL AI ASSISTANT:
   - Dynamic prompt generator for on-demand tutorials in any spoken language and script.

5. CRYPTOGRAPHIC PROOFS & PRIVACY PILLARS:
   - Interactive accordions detailing Zero-Knowledge, 100% Client-Side RAM math, Zero Tracking, and Open Algorithm auditing.
